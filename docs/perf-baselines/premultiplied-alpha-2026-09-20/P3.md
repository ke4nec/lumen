# P3：跨后端、窗口与导出联调

基点 `d4993ef`。保持 Ganesh/GL 管线，未增加生产 GPU 读回或新的渲染后端。

## Review 与修复

新增独立回归先复现 Skia 光栅 Preserve 的半透明清屏问题：damage 外旧帧用 source-over 叠在新 clear 上，连续保留使颜色/alpha 加深，修复前 108 断言中 21 个失败。两个旧帧恢复分支现用 kSrc 原样复制；三种 clear alpha、三个 DPI、纯 Preserve/局部清屏交替三轮逐字节相等。与 CPU→Skia→CPU 图片往返、v7 同命令回放合计 113 断言通过。

GPU 增加真实 GL 上下文创建、销毁、重建两轮，ResourceManager 对三种模式重新上传，再切换 CPU 后验证像素、上传次数和无待上传资源，共 22 断言通过。P1 的同 ID 覆盖/非法覆盖/卸载用例继续运行。生产源码没有新增 readPixels/glReadPixels；读回仅在测试中。

Counter 既有回退回归继续保护状态、焦点、IME、caret、renderer 先于窗口销毁与软件呈现错误传播。实际 GPU 探测失败回退由完整 CTest 的 dummy smoke 覆盖；原生 GL 运行时交换失败注入仅有 Linux LD_PRELOAD 入口，本机未执行，不能把主动上下文重建等同于运行时故障注入。

## Windows 窗口与导出

`platform_alpha_resize_restore_and_rejection_recover` 默认 dummy；设置 `LUMEN_ALPHA_REAL_WINDOW=1` 后在独立进程运行同一个测试。Windows native 驱动、direct3d11 texture / 原生 software、透明 / 不透明四组合，三次 resize、最小化恢复、三种输入模式、重复兼容转换与直接路径释放、非法输入拒绝后的再次成功提交，584 断言通过。日志 `build-alpha-after/p3-native-window.log`。软件读回透明输入为 R=128/A=255，不透明兼容输入为 R=255/A=255；其 surface 是 XRGB8888。

Gallery headless 与固定 sample 两个导出分支实际生成 raw，均为 `alpha_mode=straight`，尺寸/长度核对通过。750×875 系统字体 Buttons 样本及 headless 样本均转换为 alpha、黑/白/棋盘 PNG；路径 `build-alpha-after/p3-export-*.rgba*`。P1 的全通道穷举已经明确低 alpha 信息损失和 A=0 输出透明黑；图片反预乘只发生在显式导出动作中。

## 固定 SDL 3.2.10 宿主核对

以下源码来自 P0 固定依赖，不把源代码存在或窗口提交成功当成合成器视觉验收。

| 宿主/路径 | 源码与本轮证据 | 状态 |
| --- | --- | --- |
| Windows 原生 software | `SDL_windowsframebuffer.c` 使用无 alpha mask/XRGB8888 与 BitBlt；实测 A=255 | 呈现与生命周期已验证，逐像素透明不支持 |
| Windows SDL texture | `SDL_render_d3d11.c` 对透明窗口使用 DISCARD swapchain；`SDL_windowswindow.c` 走 DwmEnableBlurBehindWindow 且注明硬件限制 | 本机 direct3d11 提交/恢复已验证；合成器上的黑/白背景混合视觉待验证 |
| Linux X11 software/texture | `SDL_x11framebuffer.c` 从 visual 推导像素格式；GL/EGL visual 选择接收 transparent 标记 | 需要 alpha visual 与运行中的合成器，本轮无 Linux 桌面会话，待验证 |
| Linux Wayland texture | 透明窗口请求 EGL alpha_size=8，关闭 opaque region | 依赖 compositor/EGL；本轮未运行 |
| macOS texture | Cocoa 透明窗口/Metal view 将 layer.opaque 置 false | 依赖窗口服务器与 renderer；本轮未运行 |
| Wayland / macOS 严格 native software | 固定 SDL 未注册原生 CreateWindowFramebuffer；Lumen 关闭 texture framebuffer 加速并拒绝带 SDL renderer 的 surface | 现有无 GPU 回退限制，未增加支持；须在平台桌面验证或另项补齐 |

`PlatformWindow::present` 注释明确 Ok 只代表提交成功，不承诺原生逐像素透明。不能把 Windows software XRGB、Linux Xvfb 或 macOS dummy 的成功当成透明窗口完成。本轮不新增平台呈现实现；未测项保留在支持矩阵。

完整 CTest 结果与日志见计划第 9 节；测量探针未用于性能归因。P4 接着执行完整视觉样本与同机交错性能比较。
