键盘与指针契约

  • 移动：↑ ↓ 移动可用行；← → 移动可见列；Home / End 首末行；Page Up / Page Down 按视口移动。
  • 选择：单击替换选择；Ctrl / ⌘ + 单击切换；Shift + 单击或 ↑ ↓ 扩展。复选框独立切换；Ctrl / ⌘ + A 全选当前结果中可用行。
  • 编辑：双击或 Enter 进入可编辑列；编辑时 Enter 提交、Tab 提交并移到下一可编辑格、Esc 取消。输入法组合期间不触发提交。
  • 焦点：网格数据区一个 Tab 入口；导航态 Tab 离开。表头按钮和列宽手柄各自可聚焦。右键菜单支持 ↑ ↓、Enter、Esc，关闭后恢复单元格焦点。
  • 兼容性：本轮保留现有 Home / End 行导航语义。F2 需先扩展框架 Key 枚举，本轮不指定为可用入口。

数据状态与边界

  • 首次加载：保留表头和骨架，禁用数据操作；加载完成再建立 current。骨架不作为真实行计入可访问总数。
  • 空数据 / 无结果：空数据给出导入指引；无结果保留已填条件，并提供“清除筛选”，避免用户误判为数据丢失。
  • 请求失败：首次失败提供重试；刷新失败应保留旧内容，注明数据可能过期。远程请求由应用负责取消和排除过期响应。
  • 编辑遇到视图变化：排序、筛选、切列和更换编辑目标前先校验；失败阻止变化并回到错误格。滚动不能回收正在编辑的草稿。
  • 选择遇到筛选：用稳定 key 保留已选集合，展示“视图内 / 隐藏”计数；复制、批量与导出均明确范围。删行后移除失效 key 并安置焦点。

05按可验收的切片完善

以下为设计建议顺序，不表示新增发布承诺。每个切片先补无窗口行为测试，再验证 CPU / Skia 和三桌面输入。

P0 / RELIABILITY

先保证选择与编辑可靠 已落地

修饰键透传；单元格命中定位；校验失败拦截切格和切行；编辑器焦点与 Enter 提交接线；同步文档与实际行为。

验收：错误格不丢草稿；Ctrl / Shift 真正经过指针路径；重排后选中与编辑仍绑定稳定 key。2026-09-28 落地（设计文档 §16）。
P1 / DAILY WORKFLOW

交付通用桌面工作流

列拖宽、显隐、冻结与共享横向视口；搜索筛选、多列排序；类型化显示和编辑；主题密度、状态壳和可访问语义。

验收：冻结区与滚动区对齐；键盘可完成主要操作；浅 / 深 / 高对比及 200% 字体无信息丢失。列拖宽、显隐、共享横向视口（§16–17）与多列排序/当前格环/表头三态（§18）已落地。
P2 / SCALE & COMPOSITION

扩展大数据与分析组合

水平虚拟化、远程分页 / 增量加载、分组汇总、列分组、行明细；矩形选择、粘贴事务和撤销由独立契约承接。

验收：十万行 / 百列场景以实际测量定预算；虚拟化不破坏编辑、焦点和无障碍索引。
按需评估：树形数据应与 TreeList 明确组合边界；透视、公式引擎、填充柄、图表、跨表拖放、Excel 专有格式导出不进入基础 DataGrid 的本轮范围。Android / iOS 继续延期；Touch 密度仅面向桌面触屏。
