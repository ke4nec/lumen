Splitter 控件设计稿：分栏调节

两窗格 + 框架物化的分隔条 chrome：位置存绝对像素（GTK position 模式）、拖动框架直接接管（源视口滚动同先例）、分隔条可聚焦可键盘调节。本稿定义布局算法、分隔条状态、键盘/语义契约；设计文档见 docs/lumen-splitter-design.md，视觉 token 对齐 docs/lumen-visual-system-design.md。

分隔条为框架物化 chrome：键盘焦点环恒开启（visual-system §6.1），无应用级开关。

1
位置存绝对像素，不存比例 SplitterController::offset() = 分隔条 leading 缘到容器 leading 缘（GTK position / wx sashPosition 模式）；比例在 min 钳制与 resize 下漂移不可控，ratio() 仅派生只读。窗口变宽时 trailing 吃掉增量（文件管理器直觉）。
2
分隔条是框架物化 chrome 布局期生成（key = split:div:<owner>），应用只提供两个窗格子树——与 TreeList 粘性表头、集合行 Button 包装同一先例。视觉线 1px（rest）/ 3px（hover/drag），轨道 6px，命中区扩展到 16px（Medium 档 12/16/24）。
3
拖动 = 框架直接接管 命中 split:div: 且源指针非空 → 进入分隔条拖动（Slider 拖动锁定同层，命中即独占）→ 逐拍 setOffset（内部钳制）+ 请求重建 → 单帧跟手。不走应用 onScrollDrag 转发——collection d13a2ea 源视口滚动收口的同一结论。
4
min 钳制 = 顶住手感 offset 钳制在 [minLeading, W − 6 − minTrailing]（默认各 48px，应用可调）；到头继续拖动无位移。极端窄窗两窗格按最小值比例压缩，不重叠不崩。
5
嵌套即多窗格 本稿 = 水平 Splitter(树, 垂直 Splitter(列表, 预览))——窗格是任意 Widget（含另一个 Splitter / 千项 VirtualList），约束递归传播，每层位置状态独立。
6
双击复位 双击分隔条 → controller.reset() 回 initialOffsetPx（DoubleClickSink，集合控件 onActivated 同通道）。
状态、尺度与契约
全部颜色经 Theme/StyleResolver 派生，控件内无常量 · 尺度对齐视觉系统 §3.2
rest1px color.border.strong 居中于 6px 轨道
hover3px color.accent · 光标 ResizeEW/NS
drag3px accent 保持 · 两窗格逐拍实时重排（无 ghost 预览，虚影仅示意窗格变化）
focused（键盘）3px accent + 内嵌 focus ring（框架物化 chrome 布局期恒 showFocusRing=true——3px 线由 focusWidth>0 驱动；V2 不变量：不越出节点矩形）

token 依据（gallery v1 精确值）

线 rest #8c8c98（border.strong）/ hover #568cf0（accent）；surface #27272e、选中 #2e3c60——实现走三层 token 映射（splitter.line.color = color.border.strong 等），本稿不新增颜色槽位。

尺度（视觉系统 §3.2）

轨道 6px · 命中区/键盘步进 Small 12 / Medium 16（本稿）/ Large 24px · 视觉线 1→3px · 默认窗格最小 48px（controller 可调）· 步进 = 4px 网格倍数。

体积预算（M7 口径）

splitterSource 裸指针 +8B、方向 packed bool 0B → Release sizeof(Widget) 816 → 824；静态断言同步 bump（Debug 分档同集合控件规则）。

性能口径

layoutSplitter O(1) + 窗格递归；拖动逐拍 = 一次普通重排（自绘布局 ≤1ms/百节点）。窗格内千项 VirtualList 保持 O(visible)。基准场景 splitter-list 拖动 120 帧归档。

键盘契约（分隔条拥有焦点）
键行为
← / →水平 Splitter：offset ∓16px（钳制到 min/max）
↑ / ↓垂直 Splitter：offset ∓16px（视觉方向，不随内容语义翻转）
Home / Endoffset = minLeading / max（trailing 最小）
Enter / Space无操作（非命令控件；塌缩切换留后续）
Tab焦点离开（FocusManager 既有遍历）
双击reset() 回 initialOffsetPx
语义契约与四层一致
