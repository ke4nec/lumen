菜单类控件设计稿：ContextMenu / MenuBar

菜单 = M11 框架级 overlay 上的一棵 Button 子树：零新增 WidgetType、零新增 RenderCommand。本稿定义菜单面板视觉规格、菜单项状态矩阵、定位/级联与键盘契约；设计文档见 docs/lumen-menu-controls-design.md，视觉 token 对齐 docs/lumen-visual-system-design.md。

本区可交互演示：右键（或长按 Ctrl + 点击）列表区域唤起菜单 · hover「排序方式」展开级联 · 点击空白/Esc 关闭
1
零新增 WidgetType / RenderCommand 菜单面板 = overlay 上的 Container + Button 行；行 hover / pressed / 焦点 / 语义 Activate 复用 Button 的 WidgetState 路径（M11 DropdownController + 集合控件行双重验证）。框架侧唯一缝隙：PointerButton 从 HostEvent 穿透到 InteractionController + SecondaryPressSink。
2
快捷键只展示、不执行 右侧 muted 文本列（间隙 ≥ 24px，tabular-nums）；实际按键分发在应用 onKey——框架不建全局加速键表（非目标 §3）。
3
checkable = 图标槽形状指示 勾选显示 IconId::Check（16px 图标 / 20px 槽），checked 状态由应用维护（点击 → onCommand → 应用翻转 → 刷新面板）。高对比主题下不得只靠颜色（视觉系统 §11）。
4
键盘高亮 = selection 背景 + 内嵌 focus ring 与集合控件 current 行同视觉（本稿「剪切」行）；Up/Down 跳过分隔线与禁用项、不环绕；Enter 激活、Right 展开子菜单、Left 回父级、Esc 逐级关闭。
5
定位与级联 原点 = 指针 + (2,2)px；右/下缘不足翻左/上；clamp 视口 8px 边距。子菜单 = 父行右缘 + 0、顶对齐，右缘不足翻左——钳制算法与 Dropdown 共享私有实现。
6
分隔线不进语义树 1px color.border.default、水平 inset 8px；不可聚焦、无 label/action（屏幕阅读器惯例跳过）。
MenuBar MenuBarController
栏 = 主树 Ghost Button 行 · 菜单 = overlay 锚定栏项下方 · hover 切换 / Alt+助记字母 · 打开才模态
Llumen · 工具窗 — 帮助菜单打开（锚定栏项下方）
内容区（模态 barrier 覆盖：点击任意处关闭菜单，主树指针/键盘 NotHandled）
1
栏在主树、菜单在 overlay 栏 = Row + Ghost Button（key = menu:bar:<id>），参与 Tab 遍历与语义树；菜单面板经 ContextMenuController 同一面板路径锚定栏项 bounds 下方。栏不模态，菜单打开才模态。
2
打开态 = Tonal 派生 打开的栏项背景 = color.selection.background 派生（本稿 #2e3c60）；hover 相邻栏项直接切换菜单（桌面惯例，锚点随之移动）。
3
Alt + 助记字母 mnemonic 是 MenuItem/TopMenu 的显式字段（非 & 标记语法）；栏拥有焦点或菜单打开时 Alt+keyChar 打开对应菜单并高亮首项，大小写不敏感。首版不渲染下划线（TextStyle 无静态下划线通道，设计文档 §14.2）——本稿下划线仅为演示。
4
菜单打开期间键盘 Left/Right 切换顶级菜单；Esc 关闭并焦点恢复栏项；Tab 关闭全部（不逃逸模态）；Up/Down/Enter/Right/Left 子级行为同 ContextMenu 契约。
5
密度子菜单演示档位联动 菜单项最小高度随 ControlDensity 32/40/48（视觉系统 §3.2「控件最小高度」行）；「密度」子菜单勾选项即密度预览。

token 依据（gallery v1 精确值）

bg #18181b · surface #27272e · elevated #2e2e36 · line #3b3b45 · accent #568cf0 · accent-soft #2e3c60 · ink #f1f1f4 · muted #a1a1aa——实现走三层 token 映射（menu.panel.background = color.background.elevated 等），本稿不新增颜色槽位。

尺度（视觉系统 §3.2）

菜单项最小高 Small 32 / Medium 40（本稿）/ Large 48；水平内边距 8/12/16；圆角 4/6/8；面板圆角 8（卡片档）、内边距 4、宽 160–320px、最大高 = 视口 − 16（超出 ScrollView 兜底）。

elevation 与动效

menu.panel.elevation = ElevationTokens L2（(0,4)/12/64；CPU 后端扁平面降级既有规则）；打开淡入 120ms（menu.open.fadeMs 对齐 tooltipFadeMs，M10 转场驱动，reduceAnimation 归零）。

图标

IconId::Check（勾选）、ChevronRight（子菜单级联）全部既有——本控件零新增图标、零命令层改动。
