# / 缺口设计器需要它做什么首版绕行补充建议


1 · G-D7
Canvas 自绘画布控件 缺失		画布标尺、对齐 / 吸附参考线、选中手柄（8 向缩放点）、框选矩形——密集动态几何 + 自身命中交互。非模态视觉 overlay（普通 RenderCommand，CPU / Skia / GPU 三端一致）+ IconId 折线画手柄。本稿 v2 已把标尺 / 参考线 / 距离标注 / 手柄按 overlay 目标态画出并冻结 token（视觉系统 §3.5）；命中交互仍由会话输入路由承担。overlay 出现闪烁 / 命中不准时按新控件流程立项：设计文档 + mockup 同批交付；把「overlay 契约（坐标变换、与事件树互斥）」一并冻结。


2 · G-D4
通用绝对定位容器 缺失		D3 自由画布：子控件任意坐标摆放、拖动。约定「画布根 = Stack，子项一律 stackPosition」；嵌套容器内仍走布局流。本稿拖动演示即按此语义（transform 不改文档布局字段）。暂不补。若需要「布局流 / 自由定位」混合画布语义，按新容器控件立项（设计文档 + mockup + 布局测试）。


3 · G-D5
自绘编辑光标 缺失		精确编辑光标：十字（画布拾取）、斜切（角手柄）、旋转。11 种系统光标形状（含十字 Crosshair / 手形）+ overlay 模拟。暂不补。编辑体验明确不够用或 overlay 模拟出现延迟 / 闪烁时，平台层扩展自绘光标（SDL 支持自建 cursor surface）。


4 · G-D2 / P2
属性元数据覆盖 缺失（分批）		可编辑属性面板：逐属性的类型、取值范围、默认值、分组、访问器——L1–L3 控件（Grid / Image / Slider / Tabs / DataGrid 列模型 / ComboBox 选项等）尚未登记。属性面板保持只读投影（本稿形态）；L0 12 节点已可编辑。按 P2 注册表逐批登记 L1→L2→L3，每批同步字段清单守护测试；完成后属性面板才切换编辑态。


5 · —
专用缩放（Zoom）控件 缺失		画布缩放组合件：滑杆 + 百分比 + 复位 + 适应窗口。SpinController 步进（本稿）；变换由 P4 DesignCoordinateTransform 承担。暂不补。设计器自建组合件即可（Slider + Spin + Ghost 按钮），不需要框架新控件；若多个工具需要，再抽为 widgets 层组合件。


6 · G-D6 / G-D13–D16

视觉规格（Comfortable 档）


结构：标题 40 + 工具栏 52 + 主区自适应 + 诊断带（1 行 30px / 行 30）+ 状态栏 30；左栏 236 / 右栏 296 / 分隔条命中 9（可视 2px 线 + 悬停 accent）。中心区 = 页签行 32 + 画布条 / 舞台 / 环境带（或源码编辑区）。


控件：控件高 40（紧凑 32 / 触屏 48）、圆角 6（4 / 8）、水平内边距 12（8 / 16）；工具栏 Ghost 项 hover=surfaceSunken、toggle 持久底=accentContainer；Tree 缩进 20 / chevron 槽 24 / 选中标记 3px；状态栏 grip 命中归平台 resize 边。


画布辅助（§3.5 token，几何不随密度分档）：标尺带 18（次刻度 8 / 主 40）；guide 参考线 1px 玫红（暗 #f4587f / 亮 #cf2e5f，不随 accent 交换）；距离 chip = guide 底 + 反白等宽 10；选择手柄 8×8（surface 填充 + accent 描边）、命中 12；吸附阈值 6；网格 8px 点阵。


状态：选中 = accent 2px 环 + bounds chip；hover/press/focus 预览只改视觉状态不进文档 dirty；错误用 errorContent + 文字，不只靠颜色。

D1 检查器（并入 R6）：同一布局的「运行时树」视图——大纲换 dump 数据源，画布换 bounds / damage overlay，状态栏换帧统计；不依赖任何前置工程。调试运行的 HUD / bounds overlay 即复用这批能力。


D2 预览工作台（本稿主体）：只读画布 + 大纲 + 只读属性 + 环境与交互状态预览 + 诊断定位 + 热重载；examples/designer 已交付 headless 与 Linux/Xvfb 窗口 smoke，Windows / macOS 现场验收待补。v2 增补的运行 / 调试组、源码只读 + 诊断定位、标尺 / 网格 overlay 均属此外壳可交付部分。
